# Racing Alpha MCP server — shut down

**This server no longer exists.** The Racing Alpha service closed in
October 2026. The remote endpoint at `racingalpha.co.uk/api/mcp` and the
public API it fronted have been switched off, and the official MCP
Registry entry `uk.co.racingalpha/signals` has been removed.

The code in this repository (a small stdio-to-HTTP bridge) is kept for
reference only. It will not work, because the endpoint it connects to is
gone.

Thank you to everyone who built on it.
